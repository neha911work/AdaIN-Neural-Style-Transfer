Frequently Asked Questions

Everything you need to know about the application.

AdaIN stands for Adaptive Instance Normalization. It is a neural style transfer technique that aligns the feature statistics of a content image with those of a style image.

The application accepts JPG, JPEG and PNG images. For best results, use clear images with enough visual detail.

Style Strength controls the amount of transferred artistic information. A value closer to 1 applies stronger style transfer, while lower values retain more of the original content appearance.

This application uses an AdaIN-based neural style transfer architecture with a VGG encoder and a trained decoder.
